![Open Source](https://img.shields.io/badge/Open%20Source-%E2%9D%A4-red?style=for-the-badge)

A beautiful, responsive, and highly customizable card game layout template built entirely with **Flutter**. 

Whether you are building a party game, a flashcard learning app, or a trivia challenge, this boilerplate provides all the core swiping and deck-selection mechanics you need to jumpstart your development. Feel free to download, fork, and modify it to create your own unique game!

---

## ✨ Features

*   🗂 **Multi-Deck Selection:** Swipe through available decks and select one or multiple to combine them into a single game.
*   👆 **Intuitive Swiping:** Smooth, Tinder-style card swiping mechanics.
*   🔍 **Focus Mode:** Double-tap any card to fade the background and enter a distraction-free focused mode.
*   🔀 **Smart Auto-Shuffle:** Cards are dynamically and randomly shuffled every time you hit play.
*   🔄 **Endless Replayability:** Run out of cards? Simply hit the shuffle button to restart the deck instantly.
*   📖 **Built-in Instructions:** Includes a customizable "How to Play" dialog to easily explain your game's rules.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
Make sure you have Flutter installed on your machine. If you don't, check out the [official Flutter installation guide](https://docs.flutter.dev/get-started/install).

This project was updated and tested with:

* Flutter 3.41.9 (stable)
* Dart 3.11.5
* iOS deployment target 13.0

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/guifnpaiva/Card-Game-App.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd Card-Game-App
   ```
3. **Install dependencies:**
   ```bash
   flutter pub get
   ```
4. **Run:**
   ```bash
   flutter run
   ```
### Customization
This project was built to be easily modified. You can:
* Add your own custom cards and text in the data models.
* Swap out colors, gradients, and SVGs to match your game's theme.
* Modify the How to Play dialog to fit your specific ruleset.
